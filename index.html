Web7 Clock の特徴

インストール不要・完全無料

ブラウザで開くだけで時計が動きます。会員登録もログインも課金もありません。デザインごとに個別のURLがあるので、ブックマークやキオスク端末の起動URLに直接指定できます。

ホーム画面やデスクトップに追加すればアイコンから起動でき、一度開いたあとはオフラインでも表示できます。

12デザインから選べる

ネオン、サイバーパンク、レトロLED、パタパタ時計風のフリップ、ターミナル風、グラスモーフィズムに加え、森・暖炉・海といった自然系まで。用途と部屋の雰囲気で選べます。

フルスクリーンで常時表示

画面右上のボタンひと押しでフルスクリーンに切り替わります。文字サイズは画面幅に追従するので、スマートフォンから大型ディスプレイまで同じ見た目で表示できます。

Windowsアプリ版もある

常時最前面表示・ボーダーレスウィンドウ・背景の透過に対応したデスクトップアプリ版を無料配布しています。Web版と同じ12デザインをそのまま使えます。

使い方

  1. 上の一覧から好きなデザインのカードをクリックして、時計ページを開きます。
  2. 画面にマウスを乗せると右上にボタンが出ます。クリックするとフルスクリーンになります。
  3. 一覧に戻るときは、画面左上の「← COLLECTION」をクリックします。

表示される時刻は、閲覧している端末のシステム時刻（ローカルタイムゾーン）です。24時間表記が既定で、画面右上のボタンから12時間表記（AM / PM）にも切り替えられます。

出しっぱなしで使うときのコツは 常時表示ガイド にまとめています（有機ELの焼き付き対策、画面が消えないようにする設定、用途別のデザイン選び）。

こんな用途に

  • サブモニターの常時表示作業中のメインモニターを塞がずに、いつでも時刻が目に入る位置に置けます。
  • 配信・録画の画面づくりデスクトップアプリ版なら背景を透過できるので、配信画面に時計だけを重ねられます。
  • 店舗・受付のディスプレイタブレットや余ったPCをフルスクリーンにするだけで、そのまま時計として設置できます。
  • 作業用の環境映像として森・暖炉・海の自然系デザインは、動きのある背景そのものが作業BGVになります。

よくある質問

料金はかかりますか？
Web版・Windowsデスクトップアプリ版ともに完全無料です。会員登録やログインも必要ありません。
インストールは必要ですか？
Web版は不要です。ブラウザで clock.web7.tokyo を開くだけで使えます。常時最前面表示や背景の透過が必要な場合のみ、Windowsデスクトップアプリ版をご利用ください。
スマートフォンやタブレットでも使えますか？
使えます。文字サイズが画面幅に追従するレスポンシブ表示です。ただしフルスクリーンボタンはブラウザの Fullscreen API を利用しているため、iPhone の Safari では動作しません。Android の Chrome や iPad、PC では動作します。
表示される時刻はどこから取得していますか？
閲覧している端末のシステム時刻（ローカルタイムゾーン）です。サーバー時刻の取得や NTP 同期は行っていないため、表示精度は端末の時計設定に依存します。厳密な時刻合わせの用途には向きません。
12時間表記（AM / PM）に変更できますか？
できます。時計ページで画面にマウスを乗せると右上に「24H」ボタンが出るので、クリックすると12時間表記に切り替わります。設定は保存され、デザインを変えても引き継がれます。URL に ?h=12 を付けて開く方法もあるので、キオスク端末やブックマークで表記を固定したいときに使えます（?h=24 で24時間表記）。
タイムゾーンを変更できますか？
できません。閲覧している端末のローカルタイムゾーンに固定されています。海外の時刻を表示する機能は用意していません。
アラームやタイマー機能はありますか？
ありません。時刻表示に特化したサービスです。
常時表示させても画面の焼き付きは心配ありませんか？
有機EL（OLED）ディスプレイで長時間表示する場合は焼き付きにご注意ください。GRADIENT や MATRIX のように背景が動き続けるデザインを選ぶと、リスクを抑えられます。
スマホのホーム画面やPCのデスクトップに追加できますか？
できます。PWA に対応しているため、ブラウザのメニューから「ホーム画面に追加」「アプリをインストール」を選ぶとアイコンから起動できます。時計ページから追加した場合は、そのデザインが全画面で直接開きます。
オフラインでも動きますか？
動作します。一度サイトを開くと 12 デザインすべてとフォントが端末内に保存されるため、その後は通信がなくても時計が表示できます。時刻の描画も端末内で行っており、外部サービスへの通信は発生しません。
