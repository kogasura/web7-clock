デジタル時計を常時表示するコツ

サブモニターやタブレットに時計を出しっぱなしにすると便利ですが、そのまま放置すると 画面が消えたり、有機ELだと焼き付きの心配が出てきます。 Web7 Clock を常時表示で使うときに知っておきたいことをまとめました。

有機ELの焼き付き（バーンイン）対策

時計を常時表示するときに一番気をつけたいのが、有機EL（OLED）ディスプレイの焼き付きです。 時計は数字の位置がほとんど動かないため、同じ画素を同じ明るさで光らせ続けることになり、 焼き付きが起きやすい条件がそろっています。

有機ELは画素そのものが発光する仕組みで、長時間光らせた部分の輝度が戻らなくなることがあります。 一方で液晶（LCD）は構造上焼き付きは起きにくく、長時間同じ表示を続けて「残像」が見えても、 表示を変えればたいてい消えます。つまり心配が要るのは主に有機ELです。 スマートフォンやタブレット、有機ELテレビ、一部のノートPCが該当します。

リスクを下げる4つの方法

  • 背景が動き続けるデザインを選ぶ — MATRIX はコードレインが常に流れ、 GRADIENT は時間帯で背景色そのものが変わります。 OCEAN・FIREPLACE・FOREST も背景が絶えず動くので、画素ごとの負荷が平均化されます。
  • 画面の明るさを下げる — 発光量が小さいほど劣化はゆっくりになります。常時表示なら明るさは必要最小限で十分です。
  • 暗い背景のデザインを選ぶ — 有機ELでは黒い画素は消灯するので、暗い背景なら光っている画素そのものが少なくなります。 12デザインのうち明るい背景は MINIMAL のライトテーマだけで、 残りはすべて暗い背景です。
  • ときどきデザインを切り替える — 時計ページの下部にマウスを乗せると他のデザインへの切替バーが出ます。 数字の位置や色が変わるので、同じ画素に負荷が集中しません。
液晶モニターやデスクトップPCのディスプレイなら、焼き付きはほぼ気にしなくて大丈夫です。 好きなデザインをそのまま使ってください。

消費電力はデザインで変わるのか

有機ELなら変わります。 黒い画素は消灯しているため、暗い背景のデザインほど消費電力が小さくなります。 スマートフォンやタブレットを置き時計にするなら、暗い背景のデザインのほうがバッテリーに優しいことになります。

液晶ならほとんど変わりません。 液晶はバックライトが常に点灯しているので、表示内容による差は小さく、 効くのは明るさ設定のほうです。省電力にしたいなら明るさを下げるのが確実です。

なお背景アニメーションのあるデザイン（MATRIX や FIREPLACE など）は描画処理の分だけ CPU / GPU を使います。ファンの音が気になる場面では、動きの少ない MINIMAL や TERMINAL のほうが静かです。

画面が自動で消えないようにする

時計を出しておいても、しばらくすると画面が暗くなったりスリープに入ってしまいます。 Web7 Clock ではフルスクリーン中、およびホーム画面に追加したアプリとして起動している間、 ブラウザの Screen Wake Lock 機能で画面の自動消灯を防いでいます（対応ブラウザのみ）。

それでも消えてしまう場合や、より確実にしたい場合は OS 側で設定してください。 設定項目の名称は OS のバージョンによって変わるので、近い名前の項目を探してみてください。

  • Windows — 設定 > システム > 電源（とバッテリー）> 画面とスリープ
  • macOS — システム設定 > ロック画面 で、ディスプレイをオフにする時間を「しない」に
  • iPhone / iPad — 設定 > 画面表示と明るさ > 自動ロック を「しない」に。 低電力モードがオンだと自動ロックが短い時間に固定されるので、あわせてオフにします
  • Android — 設定 > ディスプレイ > 画面消灯（機種により「スリープ」）
電源につないでいないノートPCやタブレットで画面を点けっぱなしにすると、当然バッテリーは減り続けます。 常時表示で使うなら電源につないでおくのが前提です。

フルスクリーンにする

時計だけを画面いっぱいに出す方法は3つあります。

  1. 時計ページで画面にマウスを乗せると右上にボタンが出ます。クリックでフルスクリーンになります。 解除は同じボタン、または Esc キーです。
  2. キーボードショートカットでも切り替えられます。Windows の Chrome / Edge / Firefox は F11、 macOS の Safari は Control + Command + F です。
  3. ホーム画面やデスクトップに追加して、アプリとして起動する方法もあります（次の項目）。

iPhone の Safari はブラウザのフルスクリーン機能に対応していないため、右上のボタンは効きません。 この場合はホーム画面に追加して起動すると、アドレスバーのない表示になります。

ホーム画面に追加して置き時計にする

Web7 Clock はホーム画面やデスクトップに追加して、アイコンから直接起動できます。 アドレスバーやタブが出ないので、そのまま置き時計として使えます。

  • Chrome / Edge（PC） — アドレスバー右側のインストールアイコン、またはメニューの「アプリをインストール」
  • iPhone / iPad（Safari） — 共有ボタン > ホーム画面に追加
  • Android（Chrome） — メニュー > ホーム画面に追加
好きなデザインのページから追加してください。 時計ページから追加すると、そのデザインが全画面で直接開きます。 トップページから追加した場合は一覧が開きます。

追加後は通信がなくても動きます。12デザインすべてとフォントが端末内に保存されるため、 オフラインのタブレットでもそのまま時計として使えます。

Windows で常時最前面に小さく置きたい場合は、 デスクトップアプリ版 のほうが向いています。 ボーダーレスウィンドウ・常時最前面・背景の透過に対応しています。

デザイン早見表

常時表示の観点で12デザインを整理しました。秒まで見たいのか、背景が動いてほしいのかで選び分けてください。

デザイン 秒の表示 背景の動き 明るさ
NEONありなし（発光のみ）暗い
MINIMALなしなし明るい（OSのダークモードに追従）
RETRO LEDありなし暗い
MATRIXあり常に流れる暗い
GRADIENTなし（バーで表現）時間帯で色が変化時間帯による
FLIPあり数字がめくれる暗い
CYBERあり（ミリ秒まで）グリッチ暗い
TERMINALありカーソル点滅のみ暗い
GLASSあり背景がゆっくり動く暗い
FORESTなし光と霧が動く暗い
FIREPLACEなし炎と火の粉暗い
OCEANなし波が動く暗い

24時間表記と12時間表記（AM / PM）はどのデザインでも切り替えられます。 時計ページ右上の「24H」ボタン、または URL に ?h=12 を付けて開いてください。 設定は保存され、デザインを変えても引き継がれます。

用途別のおすすめ

  • 作業中のサブモニターに 視界の端でちらっと確認するので、数字がはっきり見える NEON、余計な要素のない MINIMAL、 開発中の画面に馴染む TERMINAL あたりが合います。
  • 寝室・就寝前に 明るすぎると眠りの邪魔になるので、暗くて動きの穏やかな OCEAN や FOREST を。 画面の明るさも下げておくと目に優しいです。
  • リビング・来客のある場所に GLASS や GRADIENT は インテリアから浮きにくく、時間帯で表情が変わります。
  • 店頭・受付のディスプレイに 遠くからでも読める RETRO LED、 明るい店内に合う MINIMAL が扱いやすいです。 タブレットをフルスクリーンにして立てるだけで設置できます。
  • 配信画面に重ねたい NEON や CYBER は デスクトップアプリ版 で背景を透過できるので、 配信画面に時計だけを重ねられます。
  • 作業用の環境映像として FIREPLACE・FOREST・OCEAN は背景そのものが映像作品のように動くので、時計を見るためではなく流しっぱなしにする使い方ができます。
